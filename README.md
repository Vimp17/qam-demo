## ✨ Особенности

- 🎯 **16-QAM модуляция/демодуляция** с Gray coding
- 📡 **Добавление гауссовского шума** с регулируемым уровнем
- 🔍 **Подсчет битовых ошибок** (Bit Error Rate)
- 🐳 **Docker-поддержка** для легкого развертывания
- 🔄 **Преобразование текст-биты-текст** с полным циклом обработки

## 📁 Структура проекта

Корневая директория содержит:

- **`go.mod`** — Определение Go-модуля и зависимостей
- **`main.go`** — Точка входа приложения (обрабатывает аргументы)
- **`pkg/`** — Пакеты с бизнес-логикой:
  - **`modulation/`** — Модуляция/демодуляция:
    - `qam16.go` — Реализация QAM-16 с Gray-кодированием
    - `noise.go` — Добавление гауссовского шума
  - **`utils/`** — Вспомогательные утилиты:
    - `bit_utils.go` — Конвертация строк в биты и обратно
- **`Dockerfile`** — Конфигурация для сборки образа
- **`README.md`** — Документация

> Для просмотра структуры в терминале используйте:  
> `tree qam-demo`

## 🚀 Быстрый старт

### Предварительные требования

- **Go** 1.22 или выше
- **Docker** (опционально)

### Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/Vimp17/qam-demo.git
cd qam-demo

# Сборка проекта
go build -o qam-demo
```

# Запуск
```bash
./qam-demo "Hello World" 0.1
Запуск через Docker
```

# Сборка Docker образа
```bash
docker build -t qam-demo .
```
# Запуск контейнера
```bash
docker run qam-demo "Тестовое сообщение" 0.2
```

## 💻 Использование
_Синтаксис команды_

./qam-demo <сообщение> <уровень_шума>

_Параметры_
 - сообщение - Текст для модуляции (строка)

 - уровень_шума - Уровень гауссовского шума (число с плавающей точкой)

## 📊 Примеры
### Пример 1: Низкий уровень шума
```bash
./qam-demo "Hello QAM" 0.05
```
Ожидаемый вывод:

Original message: Hello QAM

Received message: Hello QAM

Bit errors: 0

BER: 0.00%

### Пример 2: Средний уровень шума
```bash
./qam-demo "Test Message" 0.3
```
Ожидаемый вывод:


Original message: Test Message

Received message: Test Message

Bit errors: 3

BER: 2.34%


## 🔧 Технические детали
  - Модуляция 16-QAM
  - Схема кодирования: Gray code

  - Сопоставление символов:

00 → +3 | 01 → +1 | 11 → -1 | 10 → -3

Количество бит на символ: 4 бита (2 для I, 2 для Q)

## Модель канала
_Тип шума_: Аддитивный белый гауссовский шум (AWGN)

_Параметр_: Стандартное отклонение (σ)

## Обработка данных

Текст → Биты → QAM-16 Символы → + Шум → Демодуляция → Биты → Текст
